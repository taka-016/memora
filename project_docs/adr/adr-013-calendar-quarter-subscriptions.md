# ADR-013: オンラインのカレンダー予定を固定の3か月単位で購読する

## ステータス

採用。[ADR-009](adr-009-calendar-month-subscription-cache.md)を置換する。

## 決定日

2026-11-21

## コンテキスト

オンラインのグループ予定は表示月とその前後の期間を購読している。隣の月の予定が表示済みでも、初めてその月へ移ると重複する範囲の購読を追加し、初回受信待ちの表示が出る。連続して多くの月を閲覧しても、個々の購読範囲を複数年に拡大せず、受信済みの予定を使って表示を継続したい。

## 検討した選択肢

| 選択肢 | 判断 |
| --- | --- |
| 表示月を基準に前後の期間を購読する | 不採用。隣の月へ進むたびに購読期間が重なる |
| 暦月ごとに購読する | 不採用。購読を共有できる期間が短く、クエリ本数と繰り返し系列の重複取得が増える |
| 暦年を固定の3か月に区切って購読する | 採用。同じ期間の3か月で購読を共有でき、多くの月を閲覧しても個々の購読範囲を一定に保てる |
| 閲覧が進むたびに単一の購読範囲を広げる | 不採用。購読範囲が閲覧期間に応じて広がり、範囲変更時に既存範囲を含めて取得する |

## 決定事項

- オンラインのグループ予定は、1〜3月、4〜6月、7〜9月、10〜12月の固定期間ごとに、単発予定と繰り返し予定を購読する。期間をまたいで閲覧しても、個々の購読はこの固定範囲を保つ。
- 各期間の購読と受信済みデータはグループ状態の生存期間中に保持し、同じ期間の月に移るときは再購読せず、受信済みの予定を表示する。明示的な予定の再試行は表示月を含む期間の購読を対象とする。
- 期間の最初または最後の月では、隣の月を含む期間を先読みする。先読みの待機・失敗は表示中の月の読み込み状態に影響させず、対象期間を表示したときにその状態を反映する。
- 各月はその月を含む期間の受信結果を使う。期間をまたぐ単発予定と繰り返し予定の個別回を該当月に表示し、購読結果の重複による二重表示を避ける。繰り返し予定の親予定を変更検知の単位とし、期間に重なる取消情報を利用する方針は[ADR-008](adr-008-online-calendar-streams.md)を適用する。
- アプリが開始する予定購読は、明示的な再試行を除き、各グループにつき対象の3か月ごとに一度とする。グループ状態の破棄に伴って購読とキャッシュを解放する。

## 決定理由

固定期間を共有することで、隣の月を連続して閲覧するときに重複する期間の初回取得を減らせる。暦月単位より購読本数が少なく、長期間の閲覧でも新たに必要になった期間だけを個別に購読できる。境目の隣接期間を先読みすると、受信済みの場合は境目を越えるときにも表示待ちが発生しない。

## 結果

- 同じ期間内の移動や受信済みの期間への往復では、予定の購読を追加しない。
- 境目の先読みでは、まだ開いていない期間の3か月分を取得する。期間をまたぐ予定や繰り返し系列は複数の購読結果に入り得る。
- 閲覧が進むと保持する購読数とキャッシュは増えるが、単一の購読範囲は3か月のままとなる。実際の読み取り課金は予定の分布やSDKの再接続にも依存する。
