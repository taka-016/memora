# 既存オンラインデータの移行

更新前に利用者全員の旧版アプリとバックグラウンド更新を停止し、Firestoreをバックアップしてください。先にインデックスをデプロイして構築完了を待ち、対象プロジェクトの読み書き権限を持つOAuthアクセストークンを`FIRESTORE_ACCESS_TOKEN`に設定します。

`just migrate-firestore-reads <projectId> <report.json>`で対象と変換件数を確認し、同じ指定に`--apply`を付けて適用してください。完了レポートを確認してから新しいルールとアプリへ切り替えます。失敗・結果不明の場合はレポートの予定IDとFirestoreを照合してから再開してください。適用済みの予定・旅程は再変換しません。
