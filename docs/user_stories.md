# ユーザーストーリー

- [1. オンラインモードのユーザーとして、安全にアプリケーションにアクセスしたい。大切な家族の記録を守りたいから](#1-オンラインモードのユーザーとして安全にアプリケーションにアクセスしたい大切な家族の記録を守りたいから)
- [2. ユーザーとして、家族や友人をアプリに招待したい。家族や友人と記録を共有したいから](#2-ユーザーとして家族や友人をアプリに招待したい家族や友人と記録を共有したいから)
- [3. ユーザーとして、グループを管理したい。友人や家族と記録を共有したいから](#3-ユーザーとしてグループを管理したい友人や家族と記録を共有したいから)
- [4. ユーザーとして、作成したグループには必ず自分を所属させたい。自分が所属しないグループを管理することはないから](#4-ユーザーとして作成したグループには必ず自分を所属させたい自分が所属しないグループを管理することはないから)
- [5. ユーザーとして、メンバーを管理したい。グループに誰が入っているかを管理したいから](#5-ユーザーとしてメンバーを管理したいグループに誰が入っているかを管理したいから)
- [6. ユーザーとして、年表形式でグループの旅行、グループイベント、メンバー別イベントを見たい。時系列でグループの記録を整理したいから](#6-ユーザーとして年表形式でグループの旅行グループイベントメンバー別イベントを見たい時系列でグループの記録を整理したいから)
- [7. ユーザーとして、グループの旅行を管理したい。過去の振り返りや計画を立てたいから](#7-ユーザーとしてグループの旅行を管理したい過去の振り返りや計画を立てたいから)
- [8. ユーザーとして、旅行で訪問する場所を地図上で確認したい。場所を視覚的に把握したいから](#8-ユーザーとして旅行で訪問する場所を地図上で確認したい場所を視覚的に把握したいから)
- [9. ユーザーとして、旅行の旅程を管理したい。旅先での旅程をグループで共有したいから](#9-ユーザーとして旅行の旅程を管理したい旅先での旅程をグループで共有したいから)
- [10. ユーザーとして、旅行のタスクを管理したい。旅行計画とタスクを一元管理したいから](#10-ユーザーとして旅行のタスクを管理したい旅行計画とタスクを一元管理したいから)
- [11. ユーザーとして、同じ場所の過去の記録を見たい。お気に入りの場所は何度も訪れることがあるから](#11-ユーザーとして同じ場所の過去の記録を見たいお気に入りの場所は何度も訪れることがあるから)
- [12. ユーザーとして、地図表示から訪問場所を確認したい。訪れたことのある場所を俯瞰したいから](#12-ユーザーとして地図表示から訪問場所を確認したい訪れたことのある場所を俯瞰したいから)
- [13. ユーザーとして、過去の旅行を検索したい。年表から探し出すのは大変だから](#13-ユーザーとして過去の旅行を検索したい年表から探し出すのは大変だから)
- [14. ユーザーとして、グループイベントを管理したい。年表セルのメモとして過去の出来事や未来の予定を残したいから](#14-ユーザーとしてグループイベントを管理したい年表セルのメモとして過去の出来事や未来の予定を残したいから)
- [15. ユーザーとして、グループのメンバー別イベントを管理したい。特定のメンバーに関連する出来事を記録したいから](#15-ユーザーとしてグループのメンバー別イベントを管理したい特定のメンバーに関連する出来事を記録したいから)
- [16. ユーザーとして、DVCポイント契約とユースイヤーをグループ単位で管理したい。契約条件を正しく反映してポイントを運用したいから](#16-ユーザーとしてdvcポイント契約とユースイヤーをグループ単位で管理したい契約条件を正しく反映してポイントを運用したいから)
- [17. ユーザーとして、DVCポイントの利用可能数を月ごとに把握し、利用登録したい。失効を避けつつ最適にポイントを使いたいから](#17-ユーザーとしてdvcポイントの利用可能数を月ごとに把握し利用登録したい失効を避けつつ最適にポイントを使いたいから)
- [18. ユーザーとして、期間限定で付与されるDVCポイントを管理したい。ワンタイムユース等で付与されたポイントを正しく反映したいから](#18-ユーザーとして期間限定で付与されるdvcポイントを管理したいワンタイムユース等で付与されたポイントを正しく反映したいから)
- [19. ユーザーとして、年表画面でDVCポイント利用履歴を確認し、そのまま編集したい。年表とポイント管理を往復しやすくしたいから](#19-ユーザーとして年表画面でdvcポイント利用履歴を確認しそのまま編集したい年表とポイント管理を往復しやすくしたいから)
- [20. ユーザーとして、スマホのホーム画面で直近の旅程を確認したい。アプリを開かずに当日の予定をすばやく確認したいから](#20-ユーザーとしてスマホのホーム画面で直近の旅程を確認したいアプリを開かずに当日の予定をすばやく確認したいから)
- [21. オフラインモードのユーザーとして、アカウントやインターネット接続なしでアプリを利用したい。利用料金を支払わず端末内で記録を管理したいから](#21-オフラインモードのユーザーとしてアカウントやインターネット接続なしでアプリを利用したい利用料金を支払わず端末内で記録を管理したいから)
- [22. オフラインモードのユーザーとして、データをバックアップ・復元したい。端末の故障や紛失などによるデータ消失に備えたいから](#22-オフラインモードのユーザーとしてデータをバックアップ復元したい端末の故障や紛失などによるデータ消失に備えたいから)

- [23. ユーザーとして、メニューからグループ単位のカレンダーを見たい。家族や友人の予定を日付ごとに把握したいから](#23-ユーザーとしてメニューからグループ単位のカレンダーを見たい家族や友人の予定を日付ごとに把握したいから)
- [24. ユーザーとして、家族のメンバーごとに予定を色分けして管理したい。誰の予定かをひと目で見分けたいから](#24-ユーザーとして家族のメンバーごとに予定を色分けして管理したい誰の予定かをひと目で見分けたいから)
- [25. オンラインモードのユーザーとして、Googleカレンダーと連携して予定を表示したい。複数のアプリを行き来せずに予定を確認したいから](#25-オンラインモードのユーザーとしてgoogleカレンダーと連携して予定を表示したい複数のアプリを行き来せずに予定を確認したいから)

オンラインモードでは1〜20と23〜25のユーザーストーリーを利用できる。オフラインモードでは、アカウント管理、地図、地図を前提とする訪問場所管理、場所検索、現在地、共有、招待を除く1〜20のユーザーストーリーと、21〜24のユーザーストーリーを利用できる。オフラインモードのカレンダーと予定は端末内で管理し、グループ内での共有とGoogleカレンダー連携は利用できない。

## 1. オンラインモードのユーザーとして、安全にアプリケーションにアクセスしたい。大切な家族の記録を守りたいから

```gherkin
Scenario: アカウントを登録して利用を開始
  Given ユーザーはオンラインモードを利用している
  And ユーザーはアカウントを登録していない
  When ユーザーが有効なメールアドレスとパスワードでアカウントを登録する
  Then アカウント登録に成功する
  And 登録したアカウントでログインして利用を開始できる

Scenario: Google認証でログイン
  Given ユーザーはGoogleアカウントを持っている
  When ユーザーが有効なGoogleアカウントで認証を完了する
  Then ログインに成功する

Scenario: メールアドレスとパスワードでログイン
  Given ユーザーはログインしていない
  When ユーザーが有効なメールアドレスとパスワードでログインする
  Then ログインに成功する

Scenario: 無効な認証情報でログイン失敗
  Given ユーザーはログインしていない
  When ユーザーが無効なメールアドレスまたはパスワードでログインする
  Then ログインに失敗する

Scenario: 弱いパスワードは受け付けない
  Given ユーザーはアカウントを登録しようとしている
  When ユーザーが弱いパスワード（例: "password"）を入力する
  Then アカウント登録に失敗する

Scenario: ログアウト
  Given ユーザーはアプリにログインしている
  When ユーザーがログアウトを実行する
  Then ログイン状態が解除される

Scenario: オンラインモードの機能を利用
  Given ユーザーはオンラインモードでログインしている
  When ユーザーがアプリを利用する
  Then アカウント管理を利用できる
  And 地図、訪問場所管理、場所検索、現在地を利用できる
  And 記録の共有とメンバーの招待を利用できる
```

## 2. ユーザーとして、家族や友人をアプリに招待したい。家族や友人と記録を共有したいから

```gherkin
Scenario: 招待コードの生成
  Given メンバーが存在している
  When ユーザーがメンバーに対して招待コードの生成を実行する
  Then 招待コードが生成される

Scenario: アカウント登録時に招待コードを使用
  Given 有効な招待コードが生成されている
  When 招待を受けた人が招待コードを入力する
  Then 招待元のメンバーに自動的に紐づけられる

Scenario: 無効な招待コードでアクセス
  Given 招待コードの有効期限が切れている
  When 招待を受けた人が無効な招待コードを入力する
  Then メンバーに紐づけられない

Scenario: 無効な招待コードでアクセス
  Given 招待コードが存在しない
  When 招待を受けた人が無効な招待コードを入力する
  Then メンバーに紐づけられない
```

## 6. ユーザーとして、年表形式でグループの旅行、グループイベント、メンバー別イベントを見たい。時系列でグループの記録を整理したいから

```gherkin

Scenario: 年表上でのグループイベント表示

  When ユーザーが所属グループの年表を表示する
  Then 年表のグループイベント行の2024年セルに「運動会」が表示される

  When ユーザーがグループイベント行のセルを選択する
  Then フリー入力メモのダイアログが表示され、編集できる

Scenario: 年表上でのメンバー別イベント表示

  And ユーザーがメンバー別イベント行の表示領域を拡大する
```

## 9. ユーザーとして、旅行の旅程を管理したい。旅先での旅程をグループで共有したいから


## 24. ユーザーとして、家族のメンバーごとに予定を色分けして管理したい。誰の予定かをひと目で見分けたいから

[TimeTreeのメンバー別の色分け](https://support.timetreeapp.com/hc/ja/articles/207641106)を参考に、グループ内で「太郎＝青」「花子＝赤」のようにメンバー名付きの色ラベルを設定し、予定に選択する。色分けは、その予定が誰のものかを表す。家族共通の予定には「家族全員」ラベルを用意する想定とする。

```gherkin
Scenario: メンバー名付きの色ラベルを設定する
  Given ユーザーがグループ「家族」のカレンダーを利用している
  When ユーザーが色ラベルを「太郎＝青」「花子＝赤」と設定する
  Then 予定の登録時にメンバー名付きの色ラベルを選択できる
  And カレンダーでメンバー名と色の対応を確認できる

Scenario: 誰の予定かを選んで登録する
  Given グループ「家族」に色ラベル「太郎＝青」が設定されている
  When ユーザーがタイトル「通院」、開始日時、終了日時、ラベル「太郎」を指定して保存する
  Then グループ「家族」に予定が登録される
  And カレンダーに「通院」が太郎の色である青色で表示される
  And ラベル名「太郎」でも誰の予定かを確認できる

Scenario: 家族の予定をメンバーごとに見分ける
  Given グループ「家族」にラベル「太郎」の予定「通院」とラベル「花子」の予定「習い事」が登録されている
  When ユーザーがカレンダーを表示する
  Then 太郎の予定は青色、花子の予定は赤色で表示される
  And 同じメンバーの予定は同じ色で表示される

Scenario: 別の家族の予定を代理で登録する
  Given ユーザーがグループ「家族」のカレンダーを表示している
  When ユーザーが別のメンバー「花子」のラベルを選んで予定を登録する
  Then 予定は花子の色で表示される
  And 予定を入力したユーザーにかかわらず、花子の予定であることが分かる

  And ラベル名「家族全員」で家族共通の予定であることが分かる

Scenario: 終日や複数日にわたる予定を登録する
  Given ユーザーがグループのカレンダーを表示している
  When ユーザーが終日または複数日にわたる期間を指定して予定を保存する
  Then 指定した期間に予定が表示される
  And 終日の予定は時刻指定の予定と区別して確認できる

Scenario: 予定の内容と対象メンバーを変更する
  Given ユーザーが登録したラベル「太郎」の予定「通院」が存在している
  When ユーザーがタイトル、日時を変更し、ラベルを「花子」に変更して保存する
  Then カレンダーに変更後の内容が反映される
  And 予定が花子のラベル名と色で表示される

Scenario: 予定を削除する
  Given ユーザーが登録した予定が存在している
  When ユーザーが予定の削除を実行し、確認に同意する

  And 修正が必要な項目が表示される
```

## 25. オンラインモードのユーザーとして、Googleカレンダーと連携して予定を表示したい。複数のアプリを行き来せずに予定を確認したいから

Googleカレンダー連携は個人単位で設定し、連携した本人が見ているカレンダーにだけGoogle側の予定を重ねて表示する。連携した予定はグループの共有予定として登録せず、他のメンバーには共有しない。Google側への予定の作成・編集・削除や双方向同期は今回のストーリーに含めない。

```gherkin
  Given ユーザーがGoogleカレンダーを連携している
  When ユーザーがグループのカレンダーを開く
  Then 自分の画面でグループに登録した予定と自分が連携したGoogleカレンダーの予定を同じ日付上で確認できる

Scenario: 個人の連携予定を他のグループメンバーに共有しない

  And 再取得に成功する
  Then Google側の変更がカレンダー表示に反映される

Scenario: 連携できない場合に再試行する
  Given ユーザーがGoogleカレンダーの連携または予定の取得を行っている
  When アクセスが許可されないか、通信に失敗する
  Then 連携または取得を完了できなかったことが表示される
  And 再認証または再取得を行える
  And アプリに登録したグループの予定は引き続き確認できる
```
