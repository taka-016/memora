memora / Privacy

プライバシーポリシー

制定日・最終更新日：2026年11月3日

taka-016（以下「運営者」）は、memoraアプリおよびこの紹介サイトで扱う情報について、次のとおり説明します。

取得する情報と目的Googleカレンダー連携保存・削除外部サービスお問い合わせ

1. 取得する情報と利用目的

  • アカウント情報：オンライン版へのログイン・本人の識別のため、メールアドレス、アカウントの識別情報などをFirebase Authenticationで扱います。
  • 利用者が登録する情報：メンバーの名前・連絡先・生年月日等、グループ、イベント、予定、旅行、旅程、タスク、場所など、入力した内容を各機能の表示・保存・共有のために扱います。登録する内容は利用者が選択します。
  • 位置・検索情報：オンライン版で地図・場所検索を利用する際、検索語や地図の対象位置などをGoogle Maps・Placesへ送信します。現在地を使う操作では、端末の権限を得たうえで位置情報を扱います。
  • 障害情報：オンライン版では、不具合の把握・修正のため、端末・OS・アプリの情報、クラッシュやエラー情報、動作ログをFirebase Crashlyticsへ送信します。

2. Googleカレンダー連携

この機能はオンライン版で利用者が連携を選んだ場合にのみ使用します。Googleの画面でアカウントを選び、必要な読み取り権限に同意した範囲でアクセスします。memoraへのログインと、Googleカレンダーへの認可は別に扱います。

アクセスする情報と目的

Googleアカウントの識別情報・メールアドレス、カレンダー一覧、選択したカレンダーの予定情報を扱います。予定情報には識別情報、タイトル、開始・終了日時、終日の区分、説明、場所、繰り返し設定などが含まれます。Google APIの応答に主催者・参加者等の付随情報が含まれる場合がありますが、これらを予定表示や永続保存には利用しません。

利用目的は、表示するカレンダーを選択し、本人の予定をグループの共有予定と同じ画面で確認できるようにすることです。カレンダー一覧と予定の読み取り専用権限を要求し、Googleカレンダーへの書き込みは行いません。

保存・共有する範囲

  • 連携アカウントの識別情報・メールアドレスと表示対象のカレンダーIDを、本人ごとの端末内設定として保存します。設定はグループや他端末へ同期しません。
  • 取得したカレンダー一覧・予定は、端末のメモリ上で表示のために扱います。memoraの共有データベース、端末内の業務データベース、バックアップへは複製しません。
  • Google予定をグループの他のメンバーへ公開しません。運営者のサーバーを経由した予定の代理取得も行いません。
  • トークンの管理・再取得はGoogleの認証SDK・OSに委ねます。トークンを通常のアプリ設定や共有データベース、バックアップ、アプリのログに保存・出力しません。Googleのパスワードをmemoraが受け取ることはありません。

利用の制限と解除

Googleカレンダーから受け取った情報を、広告、販売・貸与、信用評価、汎用AIモデルの学習、運営者による予定の閲覧のために利用しません。memoraによるGoogle APIから受信した情報の使用および他のアプリへの転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。

アプリの「Googleカレンダー連携」から「連携を解除」を選ぶと、端末内の連携設定を削除し、カレンダー参照用の認証状態を解除して、取得済み予定の表示を終了します。Googleアカウントのサードパーティとの接続からもアクセス権を取り消せます。解除によってGoogleカレンダーの元の予定や、memoraの共有予定を削除することはありません。

3. 保存、共有、削除

オンライン版：共有するグループ・メンバー・予定・旅行等の情報をGoogleのCloud Firestoreに保存します。所属するグループ内で、機能と権限に応じて登録情報を共有します。Googleカレンダーから読み取った本人の予定は、この共有対象に含めません。

オフライン版：登録情報は端末内に保存します。Firebaseへの送信やGoogleカレンダー連携は行いません。バックアップは利用者が指定した保存先へ作成します。共有先・保存先に外部サービスを選んだ場合は、そのサービスの規約も適用されます。

端末内の設定・キャッシュ等は、連携解除、アプリのデータ消去、アンインストールなどで削除できます。外部に作成したバックアップは、保存先で別途削除してください。アプリのデータ消去だけで、オンラインの共有データが削除されるわけではありません。

グループやメンバーの削除は、通常の表示から除外し、関連記録を保持する方式です。アカウントの削除だけで共有記録が一括して消去されるわけではありません。オンラインに保存した情報の取扱い・削除については、運営者へお問い合わせください。利用目的、共有記録への影響、法令上の義務を確認して対応します。

4. 外部サービスへの通信と提供

機能の提供に必要な範囲で、認証・共有データの保存・障害解析にGoogle Firebase、地図・場所検索にGoogle Maps・Places、外部予定の取得にGoogle Calendar APIを利用します。オンライン版では時刻同期のためNTPサーバーとも通信します。これらのサービス提供に伴い、通信元のIPアドレス等が各提供先で処理される場合があります。

登録情報は、利用者が指定した共有・外部サービスの利用、法令上必要な対応を除き、第三者への販売・貸与を目的に提供しません。運営者が障害解析やお問い合わせ対応を行う際は、目的に必要な範囲で情報を扱います。

5. このWebサイト

このサイトはGitHub Pagesで配信します。運営者独自のアクセス解析ツール、広告、Cookieを利用した追跡は設置していません。GitHubは配信・セキュリティのため、IPアドレス等のアクセス情報を処理します。詳細はGitHubのプライバシーステートメントをご確認ください。

6. ポリシーの変更

機能や情報の取扱いを変更するときは、このページを更新します。Googleユーザーデータの利用目的やアクセス範囲を変更する場合は、必要な説明と同意を得てから適用します。
