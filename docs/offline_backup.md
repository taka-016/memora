# オフラインデータの手動バックアップ・復元

## 保存方式と対象

オフラインモードの設定画面から、Androidのシステムファイル選択画面を使って`.memora`ファイルの保存先と復元元を利用者が選択する。SQLiteの生ファイルは持ち出さず、バックアップ形式バージョンとDBスキーマバージョンを持つ論理データを保存する。

バックアップには次を含める。

- SQLiteの`members`、`groups`、`group_members`、`trip_entries`、`tasks`、`itinerary_items`、`member_events`、`group_events`、`dvc_point_contracts`、`dvc_limited_points`、`dvc_point_usages`
- 端末内の現在利用者
- Androidウィジェットの更新間隔
- 年齢、学年、厄年の表示設定

Androidウィジェットの対象グループ、選択日、表示キャッシュは復元可能な派生データなので含めない。SQLiteはアプリ内部ストレージとOSの端末暗号化で保護し、Android Keystoreやアプリ独自のDB暗号化は使用しない。

## バックアップファイルの保護

利用者が入力したパスワードからArgon2idで256ビット鍵を導出し、AES-256-GCMで論理データを認証付き暗号化する。形式バージョンを関連データとして認証し、salt、nonce、暗号文、認証タグと鍵導出パラメータだけをファイルへ保存する。パスワードと復号鍵は端末にもファイルにも保存しないため、パスワードを忘れた場合は復元できない。

復号前にファイル種別、ファイル形式バージョン、暗号方式、鍵導出パラメータの上限、salt、nonce、認証タグを検証する。復号後は論理形式、DBスキーマバージョン、全テーブルの過不足、設定値、現在利用者と`members`行の対応を検証する。誤ったパスワード、改ざん、破損、未対応バージョンは現在データを書き換える前に拒否する。

## 復元の原子性と排他制御

検証済みのバックアップだけを確認画面へ渡し、現在のオフラインデータを全件置換することに利用者が同意してから復元する。復元中は同じNotifierによるバックアップ・復元操作を直列化する。

DBファイルの共有ロックを通常のバックアップ読取とAndroidウィジェットのDB読取・キャッシュ公開で、排他ロックを復元で取得する。復元中は同じDB接続の通常更新も待機させ、復元途中のデータや復元前のスナップショットからウィジェットキャッシュが公開されることを防ぐ。復元、復元後の派生データ同期、保留中の同期再試行、起動時のジャーナル回復は別の共通ロックで直列化し、古い同期結果が新しい復元結果を上書きしないようにする。

復元前の業務データ、端末内利用者、設定をアプリ内部の復元ジャーナルへ先に保存する。復元は外部キーを遅延検証する単一のSQLiteトランザクションで全テーブルを置換し、端末内利用者ファイルとSharedPreferences設定をDBトランザクションの確定前に更新する。通常の例外ではDBをロールバックしてSQLite外の状態を補償する。プロセス終了や電源断で補償を完了できなかった場合はジャーナルを残し、次の通常起動またはAndroidウィジェット起動で復元前の全正本へ戻してから利用を開始する。ジャーナルは復元全体の確定後にだけ削除する。

復元成功後は現在利用者と各画面のProviderを無効化して再取得する。タイムライン画面は別画面から戻ったときに復元後の表示設定を再読込する。Androidウィジェットの対象グループが復元後も利用可能なら選択日を引き継いでキャッシュを再生成し、利用できなければ対象とキャッシュを消去する。復元した更新間隔で通常・フォールバックの定期更新を再登録する。ここでキャッシュ更新や定期更新登録に失敗しても、すでに確定したデータ復元は失敗として扱わず、保留中の同期を次の通常起動またはウィジェット起動で再試行する。再試行に失敗してもウィジェット操作は継続する。

## Androidの自動バックアップ除外

アプリの状態は暗号化した手動バックアップだけで移行する。Android 11以前向けの`fullBackupContent`とAndroid 12以降向けの`dataExtractionRules`で、アプリのroot、file、database、shared preferencesの各領域をAuto Backupと端末間転送から除外する。SQLite、端末内利用者、設定、ウィジェットキャッシュがOSによって部分的に復元され、整合しない状態になることを防ぐ。

## 検証範囲

暗号化の往復、誤ったパスワード、改ざん、破損、未対応バージョン、論理データ検証、復元失敗時のロールバックと外部状態の補償、プロセス終了後のジャーナル回復、ウィジェット読取との排他、復元後同期は自動テストで検証する。Androidのシステムファイル選択画面を使った実ファイルの往復、対象OSバージョンごとのAuto Backup・端末間転送、機内モード・再起動・release APKでの実機確認はtodo 9で行う。
