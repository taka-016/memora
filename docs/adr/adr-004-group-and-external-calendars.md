# ADR-004: グループの予定と個人の外部予定を分離して扱う

## ステータス

採用

## 決定日

2026-09-29

## コンテキスト

利用者は、家族や友人の予定を共有して調整しつつ、外部サービスで管理している自分だけの予定も同じ時間軸で確認したい。オンラインモードとオフラインモードでは利用できる保存先と外部通信の有無が異なる。

## 検討した選択肢

| 選択肢 | 判断 |
| --- | --- |
| グループ予定と個人の外部予定を分け、本人の画面で重ねて表示する | 採用 |
| 外部予定をグループの予定として保存・共有する | 不採用 |
| Googleカレンダーへの書き込み・双方向同期を行う | 不採用 |

## 決定事項

- アプリで記録する予定はグループに属する。オンラインモードでは同じグループのメンバーと共有し、オフラインモードでは端末内だけで管理する。
- 予定はタイトル、開始日時、終了日時、終日かどうか、グループ内の色ラベルを持つ。タイトルは必須とし、終了日時は開始日時より前にできない。終日と複数日にわたる予定を扱う。
- グループごとに、誰に関係する予定かを表す名前と色の組をラベルとして管理する。特定のメンバーに加え、家族全員などの共通ラベルも予定へ指定できる。
- 予定はグループ単位の月表示で確認し、対象グループと日付を切り替えられる。入口はアプリのメニューに配置する。
- 外部予定はオンラインモードでGoogleカレンダーから読み取り、連携した本人の画面にだけグループの予定と重ねて表示する。連携設定と表示対象のGoogleカレンダーは本人単位で保存し、対象グループを切り替えても表示する。
- Googleカレンダーの予定はグループの予定として保存せず、他のメンバーへ共有しない。表示上も連携元のカレンダー名を示し、アプリで記録した予定と区別する。
- Googleカレンダーへの予定の作成、編集、削除と双方向同期は行わない。再取得、失敗時の再認証と再試行、連携解除を提供し、取得に失敗してもグループの予定は表示する。連携を解除してもGoogleカレンダーとグループの予定は削除しない。
- オフラインモードでは外部予定を取得せず、GoogleカレンダーのSDKや通信処理を初期化しない。

## 決定理由

- グループで共有する予定と個人の外部予定を同じデータとして扱うと、個人の予定を意図せず他のメンバーへ公開するおそれがあるため、保存先と公開範囲を分ける。
- オンラインとオフラインでは保存先と外部通信の有無が異なるため、予定の管理範囲を明確に分ける。
- 外部サービスの障害や認証切れがあっても、アプリで記録したグループの予定を引き続き確認できるようにする。

## 結果

- グループで共有する予定と個人の外部予定が混在して表示されても、保存先と公開範囲を分離できる。
- オンラインモードではグループの予定を共有できる一方、オフラインモードの予定は同じ端末だけで利用できる。
- Googleカレンダーの障害や認証切れがあっても、アプリで記録したグループの予定は引き続き確認できる。
- 予定、色ラベル、モード別の保存実装、Googleカレンダー連携、月表示を新たに実装する必要がある。
