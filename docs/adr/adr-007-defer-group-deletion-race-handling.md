# ADR-007: グループ削除時の同時追加による不要データの残存は現時点で対策しない

## ステータス

[ADR-008](adr-008-archive-groups-and-members.md)により置換

## コンテキスト

オンラインモードでグループ削除と別端末からの予定・ラベル追加が重なると、削除済みグループに属する不要データがFirestoreに残る可能性がある。

## 決定事項

グループ削除時の同時追加による不要データの残存は、現時点で対策しない。

## 決定理由

残ったデータはアプリの動作に影響せず、現時点では不要データが残るだけであり、それを防ぐ処理を追加する必要性はないため。これはADR-008による置換前の判断理由である。

確認資料: [PR #486](https://github.com/taka-016/memora/pull/486)、[PR #491](https://github.com/taka-016/memora/pull/491)。

## 結果

不要データの残存を許容する。蓄積してデータ量の肥大化が問題になる場合に、対策を検討する。
