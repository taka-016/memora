# ADR-001: アプリモードごとにComposition Rootで依存実装を選択する

## ステータス

採用

## 決定日

2026-09-23

## コンテキスト

単一のアプリで、FirestoreとFirebase認証を使うオンラインモードと、端末内の利用者とSQLiteを使うオフラインモードを提供する。Androidウィジェットはアプリとは別のバックグラウンド処理からも更新される。

## 検討した選択肢

| 選択肢 | 判断 |
| --- | --- |
| Composition Rootでモード別の実装を選ぶ | 採用 |
| 各機能が個別にモードを判定して実装を選ぶ | 不採用 |

## 決定事項

- アプリモードに応じた具体的な実装の選択・初期化・注入はComposition Rootに集約する。Application層はインターフェースに依存し、Presentation層はモード判定や保存先の選択を行わない。
- アプリとAndroidウィジェットは同じモードで依存実装を選ぶ。
- オンラインはFirestoreとFirebase認証、オフラインはSQLiteと端末内の利用者を使用する。両モードのデータ共有・同期・移行は行わない。
- オフラインではオンライン用SDKを初期化せず、外部通信を行わない。

## 決定理由

モード判定が各機能へ分散すると、異なるモードの実装が混在し、オフラインでもオンライン用SDKや外部通信が初期化される可能性があるため。

## 結果

- UseCaseとPresentation層は具体的な保存先や外部サービスから独立する。
- オフラインでは外部通信を必要とする機能を利用できない。
