# ADR-008: グループとメンバーは削除済み保存先へ移動し関連データを残す

## ステータス

採用

## 決定日

2026-10-13

## コンテキスト

グループとメンバーを削除すると、配下の記録や所属関係にも影響する。

## 検討した選択肢

| 選択肢 | 判断 |
| --- | --- |
| 別の保存先へグループ・メンバーを退避し、関連データを残す | 採用 |
| 通常テーブルに行を残したまま非表示にする | 不採用 |
| グループ・メンバーと関連データを削除する | 退避方式へ変更 |

## 決定事項

- オンライン・オフラインとも、削除するグループ・メンバーは元のIDを保って別の保存先へ退避し、関連データとの関係を残す。
- 通常の保存先に削除済みの行を残す方式は採用せず、退避と元データの削除を原子的に行う。
- 退避したグループ・メンバーは通常の表示・選択・操作の対象から除外する。
- 退避はデータの保持を目的とし、復活機能は提供しない。
- 退避と並行する関連データの更新は許容する。退避時点で関連データを凍結する保証は設けない。

## 決定理由

- グループとメンバーを誤って削除すると、配下の記録や所属関係まで失う影響が大きいため、将来必要になったときに復活させられるよう、まずデータが残っていることを重視する。

## 結果

- 誤削除後も親の情報と関連データが残り、将来復活が必要になった際に利用できる。
- 退避データは保存容量を消費し続ける。
- 通常の保存先から親を削除しても関連データを保持できる参照構造が必要になる。
