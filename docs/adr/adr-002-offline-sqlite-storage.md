# ADR-002: オフラインデータをSQLiteへ保存する

## ステータス

採用

## 決定日

2026-09-23

## コンテキスト

オフラインモードでは、認証や外部通信を使わず、業務データと端末内の利用者を永続化する必要がある。共通の業務モデルをオンライン・オフラインで使用する。

## 決定事項

- オフラインの業務データはアプリ内部のSQLiteへ保存する。端末の保護機能を使い、アプリ独自のDB暗号化は行わない。
- オンライン専用の場所・招待データはSQLiteに保存しない。
- 保存対象外のデータを黙って欠落させず、要求を拒否する。
- 破損や未対応のDB形式を理由に既存データを自動で削除・再作成しない。

## 結果

- オフラインデータは端末内で完結する一方、場所と招待に関する機能は利用できない。
- 保存対象外のデータや未対応の形式はエラーとして扱い、既存データを維持する。
