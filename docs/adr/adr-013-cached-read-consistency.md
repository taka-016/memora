# ADR-013: キャッシュ利用時の親子の取得時点の混在を許容する

## ステータス

採用

## 決定日

2026-10-13

## コンテキスト

オンラインモードでは永続キャッシュを利用する。通信断時には、親をサーバーから、子を古いキャッシュから取得し、取得時点が混在する場合がある。

## 検討した選択肢

| 選択肢 | 判断 |
| --- | --- |
| 通常の取得結果を利用し、取得時点の混在を許容する | 採用 |
| 親子の取得時点を検証し、サーバーから再取得する | 不採用 |

## 決定事項

- キャッシュから取得した内容による編集を許可し、親子の取得時点の混在を許容する。
- 取得時点をそろえるための専用の混在検出・再取得は追加しない。
- 保存時の期待バージョンによる排他は維持する。

## 決定理由

取得時点の混在は稀なケースとして許容し、その検出・再取得による通信と実装の複雑性、およびキャッシュを利用する編集への制約を増やさないため。

## 結果

期待バージョンが古い更新は保存時に拒否するが、親と子の取得時点が混在した保存までは検出しない。
