# Independent Review

プルリクエスト操作の種類ではなく、今回の更新差分の内容を基準に独立レビューを適用する。

## 適用判定

- 今回の更新差分に実装コード、設定、生成物、テストのいずれかが含まれる場合は、独立レビューを必須とする。
- 今回の更新差分がない場合、またはドキュメントのみの場合は、独立レビューを不要とする。
- プルリクエストの作成、既存プルリクエストへのpush・本文更新、レビューコメントへの返信のすべてに同じ判定を適用する。操作の種類、返信内容、ユーザーが対応方針を指定したかどうかで例外を作らない。
- ファイル種別は拡張子だけでなく役割で判断する。ビルドスクリプト、CI定義、依存・環境設定は設定または実装として扱い、Markdownで記載された手順・設計・スキルはドキュメントとして扱う。

今回の更新差分は操作ごとに次の範囲とする。

- 新規プルリクエスト作成: 比較元ブランチからHEADまでの差分全体
- 既存プルリクエストへのpush: 前回push済みのHEADから今回pushするHEADまでの差分
- 既存プルリクエストの本文等の更新: 今回同時に反映するファイル差分。ファイル変更がなければ差分なし
- レビューコメントへの返信: その指摘への対応として今回追加したファイル差分。修正しない返信なら差分なし

## 独立レビュー

独立レビューが必要な場合は、対象差分と判断根拠をサブエージェントへ渡し、次を依頼する。

- `AGENTS.md`のレビュー方針、アーキテクチャ、コーディング規約との整合を確認する。
- 実際の発生条件と影響を確認し、ファイルを変更せず日本語で報告する。
- 新規プルリクエストでは比較元ブランチからの差分全体、既存プルリクエストでは今回の更新差分と、返信・更新内容の根拠となるPR差分・関連経路を確認する。

指摘には`review-finding-handler`を適用する。妥当な指摘があれば修正・検証・コミット後に再レビューし、妥当な指摘がなくなるまで繰り返す。

独立レビューが必要なのにサブエージェントを利用できない場合、または妥当な指摘が未解決の場合は、予定していたプルリクエストの作成・更新・push・返信を行わず状況を報告する。
